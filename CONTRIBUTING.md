# Contributing

Issues and pull requests are welcome.

## Before you open a PR

1. Install the dependencies: `pip install -r skills/course-studio/requirements.txt && python3 -m playwright install chromium`. You also need Node.js 20.10+.
2. Run `tests/smoke.sh`. It rebuilds the example course, checks every page on desktop and on phone in dark mode, and confirms that em dashes are caught.
3. If you changed how the skill behaves, add or update a case in `evals/` and a line in `CHANGELOG.md`.

## Style

- **No em dashes**, in the skill's instructions or in anything it generates. Use a comma, a colon, parentheses or a new sentence. En dashes in number ranges (`25–45`) are fine. CI fails on any em dash in the repository; run `tools/check_no_em_dash.py` to check locally.
- Keep `SKILL.md` short and move the details into `references/`. Claude reads `SKILL.md` on every use and only opens a reference when it needs it.
- Scripts use only the packages in `requirements.txt` and must run on Python 3.9.

## The bundled Anatomy engine

`skills/course-studio/anatomy/` is generated by `tools/update-anatomy.sh`. Don't edit it by hand: change the script, re-run it, and keep `THIRD_PARTY_NOTICES.md` accurate.

## Releases

Bump `version` in `.claude-plugin/plugin.json` and `.claude-plugin/marketplace.json`, add a `CHANGELOG.md` entry, and tag the commit `vX.Y.Z`.
